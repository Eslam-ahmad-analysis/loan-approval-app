## 📌 Overview

This project is an end-to-end **Machine Learning application** that predicts whether a loan application will be approved based on applicant details.

It includes:
- Data preprocessing pipeline
- Machine learning model training
- Interactive Streamlit dashboard
- Live deployment on Streamlit Cloud

---

## 🚀 Features

✔ Real-time prediction  
✔ Interactive UI (Sidebar dashboard)  
✔ Probability score for decisions  
✔ Clean ML pipeline  
✔ Production-ready deployment  

---

## 🧠 Model Pipeline

1. 📊 Data Preprocessing  
   - StandardScaler for numerical features  
   - OneHotEncoder for categorical features  

2. 🤖 Model Training  
   - Random Forest Classifier  

3. 🌐 Deployment  
   - Streamlit Web App  

---

## 📊 Input Features

- Age  
- Income  
- Loan Amount  
- Credit Score  
- Years of Experience  
- Employment Type
