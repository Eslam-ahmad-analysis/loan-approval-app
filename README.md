# 💰 Loan Approval Prediction App

A **Machine Learning web application** built with **Streamlit** that predicts whether a loan application will be approved or not based on applicant financial and personal data.

👉 Live Demo:  
https://loan-approval-app-nev3m4v2jiknir2eo3znnq.streamlit.app/

---

## 🚀 Features

- 📊 Predict loan approval in real-time
- 🎛️ Interactive dashboard UI (Sidebar inputs)
- 🎯 Probability score for decision confidence
- ⚡ Fast inference using trained ML model
- 🧠 Built with Random Forest Classifier

---

## 🧠 Model Pipeline

The machine learning workflow includes:

1. 📌 Data Preprocessing  
   - Feature scaling (StandardScaler)  
   - Categorical encoding (OneHotEncoder)

2. 🤖 Model Training  
   - Random Forest Classifier

3. 🌐 Deployment  
   - Streamlit web interface

---

## 📊 Input Features

- Age  
- Income  
- Loan Amount  
- Credit Score  
- Years of Experience  
- Employment Type
